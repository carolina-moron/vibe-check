# Job Risk Tracer

**Live site:** https://carolina-moron.github.io/job-risk-search/

Traces fake-job recruitment into scams, forced labour and human trafficking. The design rules come from the Digital Provenance Passport: every claim is sourced, no check can return "clear", and the score is always shown next to its coverage.

## What it has

- **Cases and map.** Documented cases, each with its recruitment journey on a world map, the entities involved with their former names, aliases and official actions, lure indicators, and tiered sources.
- **Check an offer.** A live browser check of an organisation, its website and the recruiter's email domain. It queries GLEIF, the New York and Colorado registries (including Colorado trade names), CourtListener, RDAP, crt.sh, Wayback, Tranco and DNS (MX and DMARC), and matches against the case catalog. It also reads the offer text for indicators based on the ILO forced-labour list and FTC scam flags. Registers that can't be queried from a browser are listed as referrals.
- **Report abuse.** An anonymous report form with no identity fields. Personal details are removed from the story in the browser, a recruiter photo becomes a perceptual hash and is never uploaded, and the reporter previews the exact record before sending.
- **Methodology.** Principles, the scope decision on people (no criminal-record or person checks, because of FCRA), the scoring and coverage model, the signal and register tables, and the limits.

## Data

| Path | Role |
|---|---|
| `data/cases/*.json` | One file per documented case. Edit these. |
| `data/cases/index.json` | Generated by `npm run build:cases` (validates first). |
| `data/signals.json` | The single risk taxonomy (the agentic job-cleaner will reuse it). |
| `data/registers.json` | Every register, with access tier (`queried`, `referral`, `planned`) and coverage. |
| `src/engine.js` | Pure checks, scoring, coverage and anonymisation. No DOM. |
| `src/config.js` | `REPORT_ENDPOINT`. `null` means reports are built and previewed but never sent. |

```sh
npm run check     # validate cases + run tests
npm run serve     # local preview
```
