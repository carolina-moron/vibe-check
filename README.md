# Digital Safety Check

*Before you trust someone online, check the situation.*

**Live site:** https://carolina-moron.github.io/job-risk-search/

Traces fake-job recruitment into scams, forced labour and human trafficking. The design rules come from the Digital Provenance Passport: every claim is sourced, no check can return "clear", and the score is always shown next to its coverage.

## What it has

- **Check.** Check a social media profile, screenshot of messages, travel invitation, housing offer, job offer, recruiter message or other suspicious interaction. Screenshots are read on-device (Tesseract.js). Results: Lower concern, Caution or Serious warning signs, with an optional anonymous submission.
- **Get help.** Verified hotlines for 22 countries and the EU (`data/help.json`), 20 anti-trafficking organisations filterable by region and whether they take requests for help (`data/partners.json`), what to do in common situations, and a quick exit. Linked from every page.
- **Cases and map.** Documented cases, each with its recruitment journey on a world map, the entities involved with their former names, aliases and official actions, lure indicators, and tiered sources.
- **News patterns.** Recent trafficking and fake-job recruitment news gathered with Tavily (`npm run news`, key from `TAVILY_API_KEY`, never shipped to the site). Rule-based extraction of countries, origin→destination corridors, typologies, events and lure indicators, mapped and linked to catalog cases. Media attention, not case counts.
- **Structural risk.** Country context from the ETC Forced Labor Structural Risk Index (`npm run import:flsri`), shown on the map, case pages and checks, never in a score.
- **Check an offer.** A live browser check of an organisation, its website and the recruiter's email domain. It queries GLEIF, the New York and Colorado registries (including Colorado trade names), CourtListener, RDAP, crt.sh, Wayback, Tranco and DNS (MX and DMARC), and matches against the case catalog. It also reads the offer text for indicators based on the ILO forced-labour list and FTC scam flags. Registers that can't be queried from a browser are listed as referrals.
- **Report abuse.** An anonymous report form with no identity fields. Personal details are removed from the story in the browser, a recruiter photo becomes a perceptual hash and is never uploaded, and the reporter previews the exact record before sending.
- **Methodology.** Principles, the scope decision on people (no criminal-record or person checks, because of FCRA), the scoring and coverage model, the signal and register tables, and the limits.

## Data

| Path | Role |
|---|---|
| `data/cases/*.json` | One file per documented case. Edit these. |
| `data/cases/index.json` | Generated by `npm run build:cases` (validates first). |
| `data/signals.json` | The single risk taxonomy (the agentic job-cleaner will reuse it). |
| `data/registers.json` | Every register, with access tier (`queried`, `referral`, `planned`) and coverage. |
| `src/engine.js` | Pure checks, scoring, coverage and anonymisation. No DOM. |
| `data/news.json` | Generated by `npm run news` (`-- --offline` re-extracts the cached fetch). |
| `data/ctdc.json` | Corridor summaries from the CTDC Global Synthetic Dataset: `npm run import:ctdc -- path/to/file.csv`. Download the CSV by hand (CTDC's terms forbid automated access); never commit it. |
| `data/flsri.json` | Generated by `npm run import:flsri` from the FLSRI repo's published build. |
| `src/config.js` | `REPORT_ENDPOINT`. `null` means reports are built and previewed but never sent. |

```sh
npm run check     # validate cases + run tests
npm run serve     # local preview
```

## Design

Brand: the Digital Safety Check logo (`assets/logo-mark.svg`, also the favicon) and its two colours, navy `#14264A` for text, rules and fills and logo blue `#2A66B8` for links, actions and state, on light paper `#EEF1F5` (13:1 and 5:1 contrast).

Layout direction from [kateebonner/personal-site](https://github.com/kateebonner/personal-site) (katebonner.ai): hairline rules, tracked uppercase lettering, a near-empty home sheet with one pencil-drawn figure. That repo has no licence, so nothing was copied: the paper grain is generated with SVG noise, the home drawing (`src/figure.js`, a thread that loops and tightens into a knot) is original, and the stylesheet is written for this project. Type is Be Vietnam Pro (SIL Open Font License) via Google Fonts.
